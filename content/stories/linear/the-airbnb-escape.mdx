# Linear 的诞生：三个 Airbnb 工程师的逃离计划

2019年，Karri Saarinen 坐在 Airbnb 的办公室里，盯着眼前那套臃肿的项目管理工具，内心充满了沮丧。

作为 Airbnb 的设计负责人，他每天要面对各种复杂的协作流程。现有的工具要么太过简陋，要么充斥着冗余的功能和繁琐的配置。**"软件应该是有魔力的，"他想，"但现在这种魔力已经消失了。"**

**转折点发生在一次偶然的对话中。**

Karri 与 Airbnb 的两位工程师——Jori Lallo 和 Tuomas Artman——在咖啡间相遇。三人聊起了各自对现有工具的失望。"我们在一家以设计闻名的公司工作，却被这些难用的工具拖累，"Karri 说，"为什么不自己做一款？"

那一刻，他们意识到这不是抱怨，而是一个机会。

三人迅速达成共识：**离职，做一款真正优雅的工具。**

他们没有宏伟的商业计划，只有一个简单的信念：软件应该让人愉悦，而不是让人头疼。他们希望打造一款能让团队专注创造、流畅协作的工具。

2019年夏天，三人正式离开 Airbnb，在旧金山的一间小公寓里开始了编码。Karri 负责设计和产品，Jori 和 Tuomas 负责技术架构。

他们给自己定下了一条铁律：**每一个像素、每一个动画都要追求完美。** 这不是为了炫耀，而是因为他们自己就是用户。"如果我们自己都不愿意用，凭什么让别人用？"

开发过程异常艰辛。他们拒绝了无数的投资人会议，选择自筹资金，只为保持对产品的绝对控制。整整一年，团队只有他们三个人。

2020年4月，Linear 正式发布。简洁的界面、流畅的动画、零学习成本——用户第一次打开就能上手。产品很快在设计圈和开发者社区中传开。

**口碑像病毒一样蔓延。**

Stripe、Figma、Vercel 等顶尖团队的工程师开始使用 Linear。他们惊讶地发现，这个工具不仅美观，更重要的是——它真的让工作变快了。

如今，Linear 已经成为全球数千家公司的首选项目管理工具，从初创企业到上市公司都在使用。而那个三人小团队，已经成长为一家估值数十亿美元的远程公司。

> "我们不是在卖一个工具，我们在提供一种更好的工作方式。当软件重新变得优雅，创造力就会自然流淌。" —— Karri Saarinen
