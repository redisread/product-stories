# Linear 的诞生：从 Jira 的挫败到产品开发的革命

2019年，Jori Lallo、Ville Vänni 和 Jussi Helin 坐在赫尔辛基的办公室里，盯着屏幕上缓慢加载的 Jira 界面，感到无比沮丧。

这三位前 Rovio（愤怒的小鸟开发商）的工程师已经受够了。他们每天都在与笨重、复杂的项目管理工具搏斗，浪费了大量本该用于创造的时间。"为什么没有一个像 Notion 或 Figma 那样快速、优雅的 issue tracker？" Jori 问道。

他们决定自己动手解决这个问题。三人辞去了高薪工作，投入全部积蓄，开始秘密开发 Linear。他们的目标很明确：打造世界上最快的 issue tracker，让开发者能够专注于真正重要的事情——编写代码。团队坚持极简主义设计哲学，拒绝添加任何不必要的功能。他们甚至在早期版本中故意省略了评论功能，强迫用户通过面对面交流解决问题。

2020年4月，Linear 正式发布。尽管功能有限，但其闪电般的速度和令人愉悦的用户体验立即吸引了硅谷顶级科技公司的注意。Figma、Shopify 和 Airbnb 成为早期采用者。到2021年底，Linear 已经筹集了超过5000万美元的风险投资，估值达到数亿美元。

> "最好的产品不是功能最多的，而是最能消除摩擦的。我们不是在构建另一个项目管理工具，而是在重新思考如何让团队高效协作。" — Jori Lallo, Linear 联合创始人
