# Linear 的绝境重生：从 Zenly 废墟中崛起的协作工具

2022年，Meta 关闭了地图社交应用 Zenly，三位核心工程师 Jori Lallo、Karri Saarinen 和 Tuomas Artman 突然失业。

这个决定成为他们职业生涯的转折点。在 Zenly 工作期间，他们对现有项目管理工具深感不满，于是自行开发了一套内部协作系统。被解雇后，他们意识到这套工具可能比 Zenly 本身更有价值。

三人迅速行动，将内部工具重构为独立产品。他们利用在 Zenly 积累的工程经验，专注于打造极致流畅的用户体验。Linear 从第一天起就坚持"速度即功能"的理念，界面简洁到极致，操作流畅如丝。早期用户包括前同事和朋友，他们提供了宝贵的反馈。团队采用远程工作模式，分布在全球各地，这让他们更深刻理解分布式团队的协作痛点。

2023年，Linear 正式发布，迅速获得 Stripe、OpenAI 等顶级科技公司的青睐。到2026年，已有超过25,000家公司使用 Linear 规划和构建产品。这款诞生于废墟中的工具，如今已成为现代软件开发团队的标配。

> "我们不是在构建另一个 Jira。我们是在重新思考整个产品开发工作流。" —— Karri Saarinen, Linear CEO
