# GitHub 的诞生：一个周末项目如何改变全球编程方式

2007年，克里斯·万斯特拉斯（Chris Wanstrath）和汤姆·普雷斯顿-沃纳（Tom Preston-Werner）坐在旧金山的一个酒吧里，抱怨着同一个问题——**Git 很难用，分享代码更是个噩梦**。

当时，Linux 之父林纳斯·托瓦兹刚刚发布了 Git，但使用它需要配置服务器、管理权限，光是搭建协作环境就要耗费数小时。现有的代码托管平台如 SourceForge 则 bureaucratic 繁琐，申请项目需要审核，界面陈旧不堪。

**"为什么代码分享不能像社交网站一样简单？"** 汤姆的一个问题点燃了火花。

2007年10月19日，周五晚上10点左右，克里斯在键盘上敲下了 GitHub 的第一行代码。随后的整个周末，他和 PJ·海耶特（PJ Hyett）以及斯科特·查康（Scott Chacon）轮流编写，用 Ruby on Rails 快速搭建原型。

他们没有商业计划书，没有融资路演，只有一个信念：**让开发者专注于代码，而不是工具**。

2008年2月，GitHub 公司正式成立；4月10日，网站公开发布。

结果超出了所有人的想象。上线第一年，GitHub 就吸引了 **10 万用户** 和 **4.6 万个公开仓库**。开发者们蜂拥而至，因为这里不再需要繁琐的申请流程，只需点击几下就能创建项目、邀请协作。

**"GitHub 让开源变得社交化。"** 一位早期用户这样评价。

从最初的四人周末项目，到如今托管超过 **4.2 亿个仓库**、服务 **1.5 亿开发者** 的全球最大代码平台，GitHub 彻底重塑了软件开发的方式。

2018年，微软以 **75 亿美元** 收购 GitHub，验证了当年那个酒吧夜晚想法的惊人价值。

> "我们不是在构建一个产品，而是在为我们自己解决一个真正的问题。最好的创业想法往往来自于你自己的痛苦。" —— Tom Preston-Werner
