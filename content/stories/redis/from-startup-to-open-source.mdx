# Redis 的意外开源：一个意大利程序员的个人项目如何改变数据库世界

2009年，意大利程序员萨尔瓦托雷·桑菲利波（Salvatore Sanfilippo）正为自己的创业公司苦苦挣扎。

当时，他的初创公司需要一个高性能的实时分析工具来处理用户行为数据。现有的数据库解决方案要么太慢，要么太复杂。在多次尝试失败后，这位自学成才的程序员决定自己动手解决这个问题。他给自己设定了一个简单的目标：创建一个能快速存储和检索键值对的系统。

萨尔瓦托雷在西西里岛的家中开始了这个项目，最初只是作为内部工具使用。他将这个系统命名为"REmote DIctionary Server"（Redis）。与传统数据库不同，Redis将所有数据存储在内存中，这使得读写速度极快。他还添加了丰富的数据结构支持，如列表、集合和有序集合，这让开发者能用更直观的方式处理数据。尽管没有正式的计算机科学教育背景，萨尔瓦托雷凭借对系统性能的深刻理解，设计出了简洁而高效的架构。他在个人博客上分享了这个项目，并惊讶地发现社区对它的兴趣迅速增长。

到2010年，Redis已经吸引了大量开发者关注，许多知名公司开始在生产环境中使用它。面对社区的热情和商业机会，萨尔瓦托雷做出了一个关键决定：将Redis完全开源，并专注于其开发而非自己的创业公司。这个决定彻底改变了Redis的命运，使其从一个个人工具成长为全球最受欢迎的内存数据库之一，被Twitter、GitHub、Stack Overflow等科技巨头广泛采用。

> "最好的代码不是最聪明的代码，而是最简单的代码。" — 萨尔瓦托雷·桑菲利波
