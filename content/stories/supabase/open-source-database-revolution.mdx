# Supabase 的开源革命：两位工程师如何挑战 Firebase 垄断

## 开头

2019年，Paul Copplestone 坐在新加坡的公寓里，对 Firebase 的限制感到深深的挫败。

## 转折

作为前 Grab 工程师，Paul 需要一个灵活、可扩展的后端解决方案，但 Firebase 的封闭生态和高昂成本让他无法构建真正创新的产品。他意识到，如果要改变现状，必须从零开始构建一个开源的替代方案。

## 发展

Paul 找到了另一位工程师 Ant Wilson，两人一拍即合。他们决定基于 PostgreSQL 构建一个现代化的 BaaS（Backend-as-a-Service）平台。PostgreSQL 是世界上最先进的开源数据库，拥有强大的功能和活跃的社区。

他们花了数月时间开发核心功能：实时数据库、身份验证、存储和函数。与 Firebase 不同，Supabase 完全开源，开发者可以自由查看、修改和部署代码。早期版本在 Hacker News 上发布后，立即引起了开发者的关注。

到 2020 年底，Supabase 已经获得了 Y Combinator 的支持，并吸引了数百万美元的投资。更重要的是，它建立了一个活跃的开源社区，贡献者来自世界各地。

## 高潮

如今，Supabase 已成为数千家公司的首选后端平台，从初创公司到大型企业都在使用它构建应用。它不仅挑战了 Firebase 的垄断地位，更证明了开源商业模式的可行性。

## 金句结尾

> "我们不是在构建另一个 Firebase 克隆，而是在重新定义开发者应该如何拥有和控制他们的数据。" — Paul Copplestone, Supabase CEO
