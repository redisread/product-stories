# Linear 的诞生：从 Notion 到 GitHub，他们如何重塑团队协作

2019年，Jori Lallo 在 Notion 中记录产品需求，在 GitHub 中追踪代码问题，却在两者之间迷失了方向。

这位前 Zynga 工程师发现，现有的项目管理工具要么过于复杂，要么功能不足。Notion 虽然灵活但缺乏结构化的工作流，而 GitHub Issues 则对非技术团队成员不够友好。这种割裂的体验让他萌生了一个大胆的想法：为什么不创建一个既简洁又强大的工具？

Jori 找到了 Karri Saarinen，一位来自 Airbnb 的设计师，两人一拍即合。他们从自己的痛点出发，开始构建 Linear。早期版本极其简单——只有任务、状态和分配功能。但他们坚持一个核心理念：速度至上。每个交互都经过精心设计，确保用户能在几秒内完成操作。

开发过程中，他们做出了一个关键决策：拒绝添加复杂的自定义字段和工作流。这与当时流行的 Jira 形成鲜明对比。"我们相信，大多数团队不需要 80% 的功能，" Jori 后来解释道，"他们需要的是剩下的 20% 能够完美运行。"

2020年1月，Linear 正式发布。尽管处于疫情初期，这款工具迅速在硅谷科技公司中传播开来。Figma、Coinbase 和 Shopify 等公司很快成为早期采用者。到2021年底，Linear 已经拥有数千个付费团队，估值超过 4 亿美元。

> "最好的工具不是功能最多的，而是让你忘记工具存在的。当你专注于解决问题而不是学习如何使用工具时，真正的生产力才会出现。"
