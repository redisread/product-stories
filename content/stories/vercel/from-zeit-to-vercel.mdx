# Vercel 的华丽转身：从通用平台到前端部署王者

【开头】2019年，Guillermo Rauch 站在十字路口。他的公司 Zeit 已经运营了四年，但方向感越来越模糊。

【转折】团队注意到一个有趣的现象：越来越多的开发者使用他们的平台部署 Next.js 应用，而不是其他类型的应用。Next.js 是 Guillermo 自己创建的 React 框架，与 Zeit 平台天然契合。这个发现让他们意识到，也许他们应该专注于前端部署这个细分市场，而不是继续做通用云平台。

【发展】做出这个决定并不容易。这意味着要放弃已经建立的品牌"Zeit"（德语中意为"时间"），重新开始。团队进行了深入讨论，分析了市场趋势和自身优势。他们发现 Jamstack 架构正在兴起，而静态站点生成器与无服务器函数的结合正是未来的方向。2020年4月，他们正式宣布将 Zeit 重命名为 Vercel，并完全专注于前端开发者体验。新名字"Vercel"源自法语"vers le ciel"，意为"朝向天空"，象征着他们对未来的雄心。

【高潮】转型后的 Vercel 迅速获得了市场的认可。GitHub 集成、即时预览、边缘网络等特性让开发者爱不释手。到2021年，Vercel 已经成为 Next.js 官方推荐的部署平台，估值超过25亿美元。许多知名公司如 Netflix、Airbnb、The New York Times 都选择 Vercel 作为他们的前端部署解决方案。

> "我们不是在构建另一个云平台，我们是在重新定义前端开发的工作流程。" —— Guillermo Rauch, Vercel 创始人
