# Linear 的诞生：设计师如何重塑软件开发工具

2019年，前 Airbnb 首席设计师 Karri Saarinen 陷入深深的挫败感。

## 转折点

在 Airbnb 工作期间，Saarinen 发现现有的项目管理工具如 Jira 过于复杂、缓慢且用户体验糟糕。每次创建任务或更新进度都像是一场战斗，而不是流畅的工作体验。他意识到，如果连世界顶级的设计团队都在使用这些工具时感到痛苦，那么其他团队的处境只会更糟。

## 发展历程

Saarinen 决定不再忍受这种状况。他与两位芬兰工程师朋友 Jori Lallo 和 Tuomas Artman 一起，在旧金山的一间小公寓里开始了 Linear 的开发。他们有一个明确的使命：打造一个速度快如闪电、界面简洁优雅、专为现代软件团队设计的工具。

团队坚持"速度优先"的原则，拒绝添加任何会降低性能的功能。他们从零开始构建，不依赖任何现成的框架，只为确保每一毫秒的响应时间都经过精心优化。Linear 的第一个版本仅用了三个月就完成，但背后是数年的思考和对工作流的深刻理解。

早期用户包括 OpenAI、Coinbase 和 Ramp 等前沿科技公司，这些团队对工具的要求极高，但也正是他们的反馈帮助 Linear 快速迭代。到 2021 年，Linear 已经吸引了超过 25,000 家公司的使用，其中包括许多硅谷最知名的初创企业。

## 高潮时刻

Linear 的突破不仅在于技术实现，更在于它重新定义了开发者工具的标准。传统工具追求功能全面，而 Linear 专注于核心体验——让团队能够快速、清晰地沟通和协作。这种极简主义哲学与当时流行的"功能越多越好"的思维形成鲜明对比，却意外地赢得了追求效率的现代开发团队的青睐。

## 金句结尾

> "我们不是在构建另一个项目管理工具，我们是在重新思考软件团队应该如何工作。" — Karri Saarinen
