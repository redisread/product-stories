# GitHub 的诞生：四个程序员的版本控制革命

2007年秋天，汤姆·普雷斯顿-沃纳（Tom Preston-Werner）在旧金山的公寓里彻夜难眠。

他和朋友克里斯·万斯特拉斯（Chris Wanstrath）刚刚发现 Git——林纳斯·托瓦兹创造的分布式版本控制系统。虽然功能强大，但命令行界面让大多数开发者望而却步。

**"我们需要让 Git 变得简单。"**

这个想法很快吸引了 P.J. 海耶特（P.J. Hyett）和斯科特·查孔（Scott Chacon）。四人一拍即合，决定创建一个基于 Web 的 Git 托管平台。

他们给公司取了个奇怪的名字："Logical Awesome LLC"。没人知道这个名字意味着什么，但他们不在乎。

**更疯狂的是他们的开发方式。**

没有办公室，没有投资，甚至没有正式的商业计划。四个人在各自的公寓里用 Ruby on Rails 开发，通过 IRC 聊天协调。每天晚上，他们会聚在一起测试新功能，经常工作到凌晨。

2008年2月8日，公司正式成立。两个月后，GitHub 向公众开放 beta 测试。

**最初的用户只有几十个。**

但这些早期用户都是核心开发者，他们立刻爱上了 GitHub 的简洁界面和社交功能。Pull Request、Fork、Issue Tracking——这些现在习以为常的功能，在当时都是革命性的。

到2009年2月，GitHub 已经拥有46,000个公共仓库。Linus Torvalds 本人也称赞："GitHub 让开源项目托管变得如此简单。"

如今，GitHub 拥有超过1亿开发者，托管着数亿个代码仓库，成为全球最大的代码托管平台。

GitHub 的成功证明了一个简单真理：最好的产品往往源于解决自己的痛点。

> "我们不是在构建一个公司，我们是在构建一个我们自己想要使用的工具。" —— Tom Preston-Werner
