# Linear 的诞生：从开发者的挫败到产品革命

2019年，前 Airbnb 设计师 Karri Saarinen 和工程师 Jori Lander 正在为他们的新项目寻找合适的项目管理工具。但他们发现，市面上的工具要么过于复杂，要么功能不足。

## 转折点

在尝试了 Jira、Trello、Asana 等数十种工具后，Karri 在一次深夜会议中愤怒地摔掉了笔记本电脑。"这些工具都在浪费我们的时间，而不是帮助我们，"他说道。就在那一刻，他们决定不再妥协——要自己打造一个完美的工具。

## 发展历程

两人投入了全部积蓄，开始秘密开发。他们坚持三个核心原则：速度、简洁和愉悦的用户体验。Jori 负责技术架构，确保系统能在毫秒级别响应；Karri 则专注于设计，每一像素都经过精心打磨。

早期版本只在小圈子内测试。他们邀请了 Stripe、Figma 和 GitHub 的工程师试用，并根据反馈不断迭代。令人惊讶的是，这些顶级公司的团队宁愿使用这个未完成的产品，也不愿回到他们付费的工具。

2020年4月，Linear 正式发布。没有大规模营销，仅靠口碑传播，第一周就吸引了数千名开发者。到年底，用户数突破10万，包括 Discord、Notion 和 Shopify 等知名公司。

## 高潮时刻

2021年，Linear 获得 Index Ventures 领投的1300万美元A轮融资。更令人瞩目的是，许多竞争对手的员工私下承认他们在使用 Linear。这款由挫败感催生的产品，正在重新定义整个行业标准。

> "最好的产品不是解决已知问题，而是揭示人们甚至不知道自己拥有的问题。" —— Karri Saarinen
