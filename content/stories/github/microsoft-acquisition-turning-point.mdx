# GitHub 的命运转折：微软收购背后的信任博弈

## 绝境中的豪赌

2018年6月，微软宣布以75亿美元收购GitHub，开发者社区瞬间炸锅。

## 转折点：从恐惧到希望

曾经以"Linux是癌症"闻名的微软，如今要收购全球最大的开源代码托管平台。开发者们担心GitHub会变成另一个被微软"拥抱、扩展、消灭"的牺牲品。但新任CEO萨提亚·纳德拉带来了不同的微软——一个拥抱开源、贡献Linux的新微软。

## 发展：重建信任的艰难之路

收购消息公布后，GitHub联合创始人克里斯·万斯特拉兹立即辞职，CTO杰森·普赖斯也紧随其后。社区的不信任情绪达到顶峰。然而，微软采取了一系列措施：保持GitHub独立运营、继续支持竞争对手的工具、甚至让GitHub CEO纳特·弗里德曼直接向纳德拉汇报。更重要的是，微软开始大规模向GitHub贡献代码，包括.NET Core和TypeScript等重要项目。三年内，GitHub用户从2800万增长到8300万，企业客户翻了两番。

## 高潮：开源新时代的开启

到2021年，微软不仅没有扼杀GitHub，反而投入巨资开发GitHub Copilot等AI工具，将GitHub推向了新的高度。这次收购成为了科技史上最成功的整合案例之一，证明了即使是曾经的"开源敌人"也能真正拥抱开源精神。

> "微软爱Linux。" —— 萨提亚·纳德拉，微软CEO
