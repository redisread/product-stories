# Linear 的诞生：三个设计师的 Jira 反叛

2019年，Karri Saarinen、Jori Lallo 和 Tuomas Artman 坐在旧金山的一间公寓里，盯着屏幕上臃肿的 Jira 界面，同时叹了口气。

## 绝望中的灵光

三人都曾是顶尖设计团队的成员——Karri 是 Airbnb 的首位设计师，Jori 在 Framer 工作，而 Tuomas 则是技术专家。他们共同的痛点是：现有的项目管理工具完全忽视了用户体验。"为什么我们每天使用的工具如此难用？" Karri 问道。这个问题成了他们创业的起点。

## 从零开始的优雅革命

他们没有立即写代码，而是花了数周时间研究问题。他们发现，大多数工具都专注于功能堆砌，而非工作流优化。"我们要做的是**减少**，而不是增加，" Jori 在笔记中写道。团队决定采用极简主义哲学：每个功能必须通过严格的"必要性测试"。

开发过程中，他们坚持每天使用自己的产品。当某个流程需要超过三次点击，他们就重写它。当加载时间超过半秒，他们就优化它。这种近乎偏执的专注，让 Linear 在早期就获得了"丝滑如德芙"的口碑。

最艰难的时刻出现在2020年初，当他们向第一批潜在用户展示原型时，有人直言："这看起来太简单了，能处理复杂项目吗？" 团队几乎动摇，但 Karri 坚持道："复杂性应该隐藏在简单之下，而不是暴露在表面。"

## 转折点与爆发

2020年3月，Linear 正式发布。恰逢全球远程办公浪潮，团队对流畅协作体验的追求正好击中了市场痛点。短短几个月内，Figma、Notion、Vercel 等顶级产品团队纷纷弃用 Jira，转投 Linear 怀抱。

更令人惊讶的是，Stripe CEO Patrick Collison 和 Slack 前 CEO Stewart Butterfield 不仅成为用户，还主动投资。"终于有人理解了，" Butterfield 说，"工具不应该成为工作的障碍。"

> "我们不是在构建另一个工具，而是在重新定义软件团队的工作方式。当你热爱自己创造的东西，其他人也会感受到那份热情。" —— Karri Saarinen, Linear CEO
