# Raycast：丹麦独立开发者的下一个目标

2018年，**Simon Støvring** 坐在哥本哈根的小公寓里，盯着屏幕上的代码。他是丹麦一位普通的独立开发者，白天给客户端做iOS外包，晚上维护自己开发的 macOS 工具——一个叫 **Raycast** 的启动器插件。

当时他完全没想过，这个花了他"几个周末"做的 小工具，会在5年后成为Mac生态的现象级产品。

## 意外的开端

故事要从2017年说起。Simon当时在用 macOS 自带的 Spotlight 功能，但他总觉得少了点什么。

> "Spotlight 很好，但它不支持自定义命令。我想查天气要看股票，还要能快速操作 GitHub——这些 Spotlight 都做不到。"

于是他花了大约 **200 小时**，写了一个开源的 macOS 启动器。代码托管在 GitHub 上，完全免费，没有任何商业模式。

2018年，他把项目改名叫 **Raycast**，开始认真维护。

## 疯狂的2023年

2023年，Raycast 的故事发生了戏剧性转折。

**3月**，Raycast 推出 Store，允许开发者销售付费扩展。这是产品的一个重要里程碑。

**6月**，Raycast 宣布完成 **1800 万美元 A 轮融资**，估值达到 **1.5 亿美元**。此时团队只有 **15 人**。

这是独立开发者的终极逆袭——从一个周末项目，到估值上亿美元。

## 下一个目标

2024年，Raycast 团队扩充到 **50 人**，开始向更广阔的平台扩展。

> "我们不想成为另一个Alfred，"Simon 在一次采访中说。"我们想成为 Mac 上的 AI 操作系统。"

Raycast 的愿景是：让任何用户都能通过自然语言指令，完成复杂的自动化任务。
