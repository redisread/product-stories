# Discord：从游戏失败的灰烬中建起的语音帝国

2013年，Jason Citron 正在经历一场创业失败。

他的游戏公司 Hammer & Chisel 花了将近两年时间开发了一款名为 "Fates Forever" 的移动端 MOBA 游戏——概念类似《英雄联盟》，但专为平板电脑设计。发布后，这款游戏的评价不错，玩法扎实，画面精良，但商业上彻底失败了。原因简单残酷：移动端 MOBA 的市场根本就不存在。玩家不愿意在触摸屏上玩需要精确操作的团队竞技游戏，移动玩家的注意力碎片化，根本撑不起这种需要30分钟专注对局的游戏类型。

公司账上的资金还够支撑几个月。Citron 和他的联合创始人 Stan Vishnevskiy 需要做一个决定：是继续尝试另一款游戏，还是彻底转型？

答案藏在他们开发 Fates Forever 的过程中。整个开发周期里，团队一直在用 Skype 进行语音协作，玩自己游戏的内测版时也是如此。Skype 慢、卡、经常崩溃，更致命的是，一旦有人需要开启视频会议，整个通话质量就会急剧下降。他们也试过 Teamspeak 和 Mumble，这两个产品是游戏玩家圈子里的老牌语音工具，功能上比 Skype 专业，但界面复杂到需要专门花时间学，服务器还需要自己搭建和维护。

Citron 意识到一件事：**他们开发游戏的过程里，花在"找一个好用的语音工具"上的时间和挫败感，可能比任何一个特定的玩家还要多。** 如果他们有这个问题，无数玩家也有。

## 用6个月时间押注一个想法

2014年底，Citron 做了一个对赌性质的决定：用公司剩余的资金，转型做一个游戏玩家语音通话工具。这不是经过充分市场调研后的战略选择，这是一个快要沉船的创业者在溺水前抓住的最近的那块浮木。

核心的产品定义异常简单：**安装完就能用，不需要任何服务器设置，不需要账号注册就能加入语音房间，完全免费，延迟要比 Skype 低一半。**

这四点要求，每一点单独看都不难，但要同时实现，需要在技术架构上做出大量非常规的选择。Citron 的团队选择了集中式服务器架构而非点对点架构——这意味着更高的运营成本，但换来了更稳定的通话质量和更低的延迟。为了覆盖成本，他们一开始的商业模式预想是游戏道具销售，后来发现这条路行不通，才转向了后来的 Nitro 订阅模式。

2015年5月15日，Discord 正式发布。

## 名字背后的逻辑

关于名字的来历，网络上流传着一个"酒吧偶然听到"的版本，但实际情况更接近于一个务实的品牌决策过程。

Citron 的团队需要一个名字，条件是：短、响亮、可以注册到域名、没有被其他知名科技公司用过、听起来和游戏相关但不显得低端。"Discord"（不和谐）这个词被提出来时，有人担心它有负面含义——"不和谐"听起来更像是问题，而不是解决方案的名字。

Citron 的反驳是：正是因为这个词有对抗性，它才有记忆点。游戏玩家文化里向来不惧怕"冲突"这种感觉——竞技游戏的本质就是制造和化解冲突，而 Discord 这个工具的存在，就是为了让玩家在语音频道里协调解决这种冲突。名字里的"不和谐"，恰恰是对使用场景的一种反讽性描述。

"discord.com" 这个域名当时并没有被主要科技公司占用，Citron 以一个合理的价格注册下来。名字就这样定了。

## 发布后的48小时

Discord 公开发布的前两天，Citron 把链接发到了几个游戏社区——主要是 Reddit 的几个游戏相关板块，以及一些游戏公会的论坛。他没有做任何媒体公关，没有预备发布事件，也没有在 Product Hunt 上推送（Product Hunt 当时还没有今天的影响力）。

第一天结束，有约3000人注册。第三天，《最终幻想 XIV》的几个大型公会开始在他们内部推荐 Discord，因为这款游戏需要大量语音协调，而此前他们一直在用 Teamspeak 但体验不好。这波来自 FFXIV 社区的传播，让 Discord 在发布后的第一个月内用户数突破了2万。

口碑传播的速度比任何付费获客都快。游戏公会有一个独特的结构性优势：他们天然需要把新成员带入同一个语音工具，这意味着 Discord 的每一个核心用户都会主动带来多个新用户。这个增长飞轮一旦启动，几乎不需要外力维持。

2016年底，Discord 的注册用户数超过了2500万。这时候，投资方开始排队。Benchmark 在2017年领投了 A 轮，融资额达数千万美元。

## 意外的扩张：从游戏玩家到所有人

Discord 最大的一次身份转变，发生在2020年新冠疫情期间——但这次转变并不完全是 Citron 主动推动的。

疫情封控让数亿人被困在家里，人们需要一个能够在线聚集的地方，不仅仅是为了游戏，而是为了社交、学习、工作。Discord 的服务器（Server）结构——一个服务器里可以有多个文字频道和语音频道，管理员可以设置不同权限——天然适合各种群体的组织需求。

学生们开始在 Discord 上组建学习小组；音乐人开始用它进行在线排练；政治组织用它协调活动；股票散户社区在上面讨论投资策略（GameStop 事件中，散户投资者的主要协调平台之一就是 Discord）；连 NASA 也开设了官方 Discord 服务器用于科普互动。

Discord 在这段时期的月活用户数从1亿左右飙升至接近2亿。更关键的是，用户构成发生了根本性变化：游戏相关用户从曾经的约90%降至约30%，非游戏社群成为主流。

面对这个变化，Discord 做出了一个与大多数平台相反的选择：**不主动强推商业化，不在聊天和语音里插入广告，不把算法推荐塞进用户的信息流。** Citron 多次强调，Discord 的核心价值主张是"你和你的朋友们的私密空间"，一旦引入算法推荐，这个核心属性就会被破坏——用户看到的将不再是他们关心的朋友的消息，而是平台认为"能让他们多停留5分钟"的内容。

2021年，Discord 拒绝了微软约120亿美元的收购邀约。当时这个决定被许多人认为是疯狂的——毕竟这是有史以来对一家游戏相关公司最大的收购出价之一。Citron 在内部信中的解释是：独立运营是保持产品方向不被外部战略目标干扰的唯一方式。

2021年完成5亿美元融资后，Discord 的估值达到了150亿美元。

从2013年游戏失败的灰烬，到2021年价值150亿美元的社区平台，Discord 走过了不到八年。这个故事里最反直觉的一点是：它的成功不是因为它在游戏领域做了什么颠覆性的创新，而是因为它解决了一个游戏玩家每天都在忍受的、足够小但足够真实的痛苦——在游戏时，找一个好用的语音工具，实在太难了。

> "有时候最简单的决定，反而是最正确的。" — Jason Citron
