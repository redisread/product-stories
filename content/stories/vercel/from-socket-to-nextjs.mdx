# 从 Socket.IO 到 Next.js：Vercel 创始人的开源逆袭之路

2015年，29岁的 Guillermo Rauch 站在人生的十字路口。他的上一家公司已经失败，但他的开源项目 Socket.IO 却在全球开发者中广受欢迎。

## 绝境中的灵光一闪

Rauch 意识到，虽然 Socket.IO 解决了实时通信的问题，但现代 Web 开发仍然面临更根本的挑战：复杂的构建工具、缓慢的部署流程、以及前后端分离带来的性能问题。他决定创建一个全新的框架，让开发者能够专注于产品本身，而不是基础设施。

## 从 ZEIT 到 Vercel

Rauch 在 2015 年创立了 ZEIT（后来更名为 Vercel），并发布了 Next.js——一个基于 React 的服务器端渲染框架。最初，这只是一个个人项目，但很快吸引了大量开发者的关注。Next.js 的核心理念是"零配置"：开发者只需编写代码，框架会自动处理代码分割、静态生成、服务器端渲染等复杂任务。

ZEIT 的早期团队只有几个人，他们住在旧金山的一个小办公室里，每天工作 16 小时。Rauch 亲自回复每一个 GitHub issue，甚至在深夜修复 bug。这种对开发者体验的极致关注，让 Next.js 迅速在社区中建立了口碑。

2020 年，ZEIT 正式更名为 Vercel，这个名字来源于 "vertical"（垂直）和 "accelerate"（加速）的结合，象征着公司帮助开发者垂直加速产品开发的使命。同年，GitHub CEO Nat Friedman 和 Accel 领投了 2100 万美元的融资。

## 商业模式的突破

Vercel 的真正突破在于将开源框架与商业平台完美结合。Next.js 保持完全开源，而 Vercel 平台则提供无缝的部署体验。这种模式让公司在 2021 年获得了 1.02 亿美元的 C 轮融资，2024 年更是以 32.5 亿美元的估值完成了 2.5 亿美元的 E 轮融资。

如今，Vercel 拥有 550 名员工，服务包括 Netflix、Airbnb、TikTok 在内的数千家客户。但 Rauch 从未忘记自己的初心：让 Web 开发变得更简单。

> "最好的技术不是最复杂的，而是最能让开发者专注创造的。" —— Guillermo Rauch
