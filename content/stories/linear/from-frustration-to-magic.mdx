# Linear 的魔法重生：从 Jira 的挫败到产品开发的革命

2019年，Karri Saarinen、Jori Lallo 和 Tuomas Artman 坐在赫尔辛基的一家咖啡馆里，沮丧地盯着屏幕上复杂的 Jira 界面。作为经验丰富的设计师和工程师，他们无法理解为什么现代软件开发工具如此反人类。

**转折点发生在一次深夜的头脑风暴中**。Karri 突然放下咖啡杯说："我们为什么不自己做一个？" 这个简单的问题点燃了三人的激情。他们意识到，问题不在于功能缺失，而在于整个用户体验的崩塌。软件开发本应是创造性的过程，却被繁琐的工具变成了机械劳动。

接下来的六个月，三人全职投入这个秘密项目。他们没有融资，没有办公室，只有对"魔法般体验"的执着追求。Karri 负责设计哲学，Jori 专注产品策略，Tuomas 构建技术架构。他们每天工作16小时，反复测试每一个交互细节。**关键突破来自一个反直觉的决定：删除功能而不是添加功能**。他们砍掉了80%的 Jira 功能，只保留核心工作流。"速度就是功能，" Karri 在内部会议上强调，"如果团队需要两分钟才能创建一个任务，那这个工具就已经失败了。"

2020年4月，Linear 正式发布。**上线第一周就吸引了数百个团队注册，包括 Figma、Stripe 和 Slack 等顶尖公司**。这些早期用户不仅是客户，更是共同创造者。Patrick Collison（Stripe CEO）和 Dylan Field（Figma CEO）都成为了天使投资人，因为他们看到了 Linear 解决的正是他们自己的痛点。到2021年底，Linear 已经处理了超过1000万个工作项，团队规模扩展到50人，但依然保持着创始人的极致品质标准。

> "计算机曾经是魔法般的存在。我们的使命就是找回那种魔法，让软件开发重新变得令人愉悦。" — Karri Saarinen, Linear CEO
