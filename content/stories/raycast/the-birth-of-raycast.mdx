# Raycast：两个前Facebook工程师如何重新定义Mac开发者生产力

2019年的一个下午，Thomas Paul Mann 和 Simon Støvring 坐在哥本哈根的一家咖啡馆里，对着各自的 MacBook 叹气。作为前 Facebook 工程师，他们每天都在用 Alfred、Spotlight 等生产力工具，但这些工具要么界面陈旧，要么扩展困难，要么功能有限。他们想要一个既强大又美观、真正为现代开发者设计的工具。

当时的 Mac 生产力工具市场已经相当成熟。Alfred 自 2010 年推出以来积累了大量忠实用户，功能强大，支持自定义工作流、剪贴板历史、文件搜索等。但界面停留在 2010 年代，工作流开发基于 AppleScript 或 Bash，与现代开发工具的集成有限。Spotlight 简单易用但功能基础，不支持自定义扩展。LaunchBar、QuickSilver 等工具也面临类似问题。

与此同时，开发者的工作方式在变。SaaS 工具激增，开发者用着 Jira、Linear、GitHub、Figma、Notion 等数十种工具。远程工作普及，需要更高效地管理任务和切换上下文。开发者对 UI/UX 的期望越来越高。现代工具都提供 API，为集成创造了可能。

离开 Facebook 后，两人在哥本哈根租了小办公室开始开发 Raycast。设计理念很清晰：像 VS Code 命令面板一样通过快捷键唤起、输入命令执行操作的命令面板；采用 macOS 设计语言的现代界面；用 TypeScript 和 React 开发扩展以降低门槛；与 GitHub、Jira、Linear、Slack 等深度集成；用 Swift 和 AppKit 确保原生性能。

两人花了数月打磨核心体验。搜索算法既要快速又要智能排序，界面动画每个过渡都要流畅自然，扩展 API 既要强大又要简单易用，性能上启动速度、内存占用、响应时间都要优化。即使在资金紧张的情况下，他们也拒绝妥协产品质量。

2020年10月，Raycast 发布 Beta 版本，最初只在前 Facebook 同事、开发者朋友和社区内测试。反馈很积极。"这就像是 Alfred 和 VS Code 命令面板的结合体，但更现代、更美观。"一个早期用户评价道。

差异化优势很快显现。界面采用 macOS Big Sur 的设计风格，圆角、半透明、阴影，与 Alfred 的过时界面形成鲜明对比。扩展用 TypeScript 和 React 开发，开发者可以用熟悉的 Web 技术创建功能：

```typescript
// 一个简单的Raycast扩展示例
import { showToast, Toast } from "@raycast/api";

export default async function Command() {
  await showToast({ style: Toast.Style.Success, title: "Hello World" });
}
```

内置的开发者工具集成也很实用：GitHub 查看 PR 和 Issue、Jira/Linear 管理任务、剪贴板历史、计算器、颜色选择器、窗口管理。启动速度极快，界面响应流畅——得益于原生 Swift 开发和对性能的持续优化。

Beta 发布后，Raycast 通过邀请制逐步扩大用户群，每个用户都可以邀请朋友。到 2020 年底，已经有数千名 Beta 用户，包括许多知名的开发者和技术领袖。

2021年是 Raycast 的爆发之年。4月，1.0 正式发布，迅速在开发者社区走红。Product Hunt 上获得数千个赞，技术博客和 YouTube 频道纷纷评测，Twitter 上大量开发者分享使用体验。"Raycast 已经取代 Alfred，成为我的 Mac 必备工具。"

同年推出的重要功能包括：Store（扩展商店）、AI Beta（通过自然语言执行命令）、团队功能（共享扩展和配置）、脚本命令（运行 Shell 脚本和 AppleScript）。Store 上线后社区贡献了大量扩展，到年底超过 500 个。2021年底，Raycast 完成由 Accel 领投的 1500 万美元 A 轮融资。

2022年，菜单栏管理、计划任务、更多集成（Figma、Notion、Asana、Trello）、改进的搜索（模糊匹配和别名）相继推出。年底活跃用户超过 10 万。

Raycast 的主要竞争对手是 Alfred 和 Spotlight。Alfred 有庞大的用户基础和丰富的工作流生态系统，但界面过时、工作流开发门槛高、更新频率较低。Spotlight 功能有限，不支持自定义扩展。新兴的 Almighty、HapiGo 等工具市场份额较小。

面对竞争，Raycast 选择了几条路：在每个细节上追求极致的产品体验，从动画流畅度到搜索准确性到扩展易用性；通过降低扩展开发门槛吸引社区贡献，到 2023 年 Store 超过 1000 个扩展；保持每月发布新功能的快速迭代；2023 年推出 AI 功能，允许用户通过自然语言执行命令。

2023年是关键转折点。Raycast 推出了深度集成到命令面板的 AI 助手——Raycast AI。它能感知当前使用的应用上下文来提供帮助，不仅能回答问题，还能执行命令。"不只是 ChatGPT 的包装，而是真正集成到工作流的 AI。"用户这样评价。同年还推出了 Raycast for Teams，团队可以共享扩展、配置和快捷方式，让 Raycast 从个人工具演变为团队协作工具。2023年底，用户数突破 30 万。

2024年，更强大的 AI 功能（编写代码片段、分析数据）、更多企业功能（SSO、审计日志、管理控制台）、更快的启动速度和更低的内存占用让 Raycast 成为 Mac 开发者的标准配置，许多公司的入职流程中都包括安装 Raycast。

到 2024 年，Raycast 活跃用户超过 50 万，几乎全部是 Mac 上的专业开发者和创意工作者。Store 有超过 1500 个扩展。年收入估计超过 1000 万美元。技术栈上，前端用 React + TypeScript 开发扩展，桌面应用用 Swift + AppKit 确保原生性能，后端用 Go + PostgreSQL 处理云服务和同步。

> "我们不是在构建另一个工具，而是在重新思考开发者应该如何与计算机交互。Raycast 始于我们对现有工具的不满——为什么生产力工具不能像现代应用一样美观、流畅？为什么扩展开发要如此复杂？两年来，我们专注于回答这些问题。今天，Raycast 不仅是一个启动器，更是开发者的日常伴侣。真正的创新不在于添加更多功能，而在于让每个交互都恰到好处。" —— Thomas Paul Mann，Raycast 联合创始人兼 CEO
