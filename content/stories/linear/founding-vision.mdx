# Linear 的诞生：三位芬兰设计师如何重塑软件开发工具

【开头】2019年，Karri Saarinen、Jori Lallo 和 Tuomas Artman 坐在赫尔辛基的一家咖啡馆里，讨论着一个共同的痛点：现有的项目管理工具让软件开发变得痛苦而非愉悦。

【转折】这三位曾在知名科技公司工作的芬兰人意识到，问题不在于功能缺失，而在于设计理念的根本错误。他们决定放弃高薪工作，创建一款以"质量"和"体验"为核心的工具，而不是又一个功能堆砌的竞品。

【发展】他们将公司命名为"Linear"，寓意线性进步和清晰的工作流。从第一天起，他们就坚持完全远程的工作模式，相信最好的人才不应该被地理位置限制。团队只有三人，却设定了极高的标准：每个像素、每个交互、每行代码都必须体现对工艺的执着。他们拒绝了传统的OKR和A/B测试，而是依靠判断力、客户洞察和品味来做决策。早期用户主要是他们的朋友和前同事，这些挑剔的开发者成为了最严格的测试者。

【高潮】短短几年内，Linear 从一个简单的内部工具成长为数千家科技公司的首选，包括 Figma、Stripe、Slack 等行业巨头。投资者包括 Patrick Collison（Stripe CEO）、Stewart Butterfield（Slack 前 CEO）等顶级创业者。到2025年，Linear 已达到10亿美元估值，但团队仍保持精简，只有约100人分布在15个国家。

【金句】> "质量不会自动产生，它需要刻意为之。我们相信，当工具本身足够优雅时，伟大的软件就会自然涌现。" — Karri Saarinen, Linear CEO
