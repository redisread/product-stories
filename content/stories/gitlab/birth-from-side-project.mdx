# GitLab 的诞生：一个乌克兰程序员的 side project 如何成长为百亿公司

2011年，Dmitriy Zaporozhets 在乌克兰的一家软件公司工作。每天，他都要和分散在不同地方的开发者协作，但现有的工具要么太贵，要么太难用。**"我只是想要一个简单、开源的代码协作平台。"** 找不到满意的解决方案，他决定自己动手写一个。

深夜的公寓里，他用 Ruby on Rails 敲下了第一行代码。这个项目没有商业计划，没有融资目标，纯粹是为了解决自己的痛点。他把代码放到 GitHub 上，开源给所有人使用。当时的他并不知道，这个决定将开启一段传奇。

## 从海牙到哈尔科夫：两个陌生人的相遇

2012年，在荷兰海牙，Sid Sijbrandij 正在寻找更好的代码管理工具。一次偶然的机会，他在 Hacker News 上发现了 GitLab。**"我被惊艳到了——这正好是我需要的东西。"** Sid 不仅开始使用 GitLab，还开始贡献代码。

几个月后，Sid 主动联系了 Dmitriy。两个从未谋面的人，一个在乌克兰哈尔科夫，一个在荷兰海牙，开始了远程协作。Sid 提议：**"我们一起把它做成一家公司吧。"** Dmitriy 起初犹豫——他只想做好开源项目。但 Sid 的坚持和对愿景的描述最终打动了他。

2014年，GitLab Inc. 正式成立。公司没有办公室，只有两名创始人隔着 **2,300 公里** 的距离，用视频通话和 Git 协作。

## 全远程的疯狂实验

从第一天起，GitLab 就采用全远程工作模式。这在 2014 年几乎是闻所未闻的。投资人质疑："没有办公室，团队怎么协作？"客户担心："没有总部，公司可靠吗？"

但 GitLab 用实际行动回应了质疑。2015年，他们入选 **Y Combinator** 冬季批次，成为该批次中第一个全远程公司。同年，他们获得了 **150 万美元** 种子轮融资。Alibaba、IBM 等大客户开始采用 GitLab。

到 2021 年，GitLab 已有 **1,500 名员工**，分布在 **65 个国家**。同年 10 月，GitLab 在纳斯达克上市，市值超过 **100 亿美元**。

> "Everyone can contribute. 我们的使命是让每个人都能参与创造。" —— Sid Sijbrandij, GitLab 联合创始人兼 CEO
