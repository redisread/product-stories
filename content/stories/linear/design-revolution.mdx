# Linear 的设计革命：从 Airbnb 到重塑软件开发工具

【开头 - 50字】
2019年，前 Airbnb 设计总监 Karri Saarinen 厌倦了市面上糟糕的项目管理工具。

【转折 - 100字】
在 Airbnb 工作期间，他目睹了团队如何被笨重的 Jira 和混乱的 Trello 拖慢进度。每次 sprint 规划会议都变成了一场噩梦，工程师们抱怨不断，设计师感到被边缘化。Karri 意识到，问题不在于流程，而在于工具本身。

【发展 - 200字】
Karri 联合了前 Framer 工程师 Jori Lallo 和 Tuomas Artman，三人决定从零开始打造一款真正为现代软件团队设计的工具。他们拒绝了传统 issue tracker 的复杂性，专注于极简主义和流畅体验。团队完全远程工作，分布在北美和欧洲，却保持着惊人的同步效率。他们每天使用自己正在开发的产品，快速迭代，甚至在早期就吸引了 Stripe、Figma 和 Vercel 等顶尖公司的注意。Patrick Collison、Dylan Field 和 Guillermo Rauch 等硅谷重量级人物纷纷成为天使投资人，因为他们看到了 Linear 解决的痛点正是他们自己每天都在经历的。

【高潮 - 100字】
Linear 发布后迅速在开发者社区走红，不是因为营销，而是因为口碑。团队坚持"设计是代码的一部分"的理念，将每一个 UI 细节都打磨到极致。到 2023 年，数千家科技公司已经将 Linear 作为默认的项目管理工具，包括许多 Fortune 500 企业。

【金句结尾 - 50字】
> "我们不是在构建另一个工具，而是在重新定义软件团队应该如何协作。" — Karri Saarinen
