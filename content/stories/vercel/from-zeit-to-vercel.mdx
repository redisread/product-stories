# Vercel 的绝境重生：从 ZEIT 到全球开发者平台

2020年初，新冠疫情席卷全球，科技行业陷入寒冬。ZEIT 公司的工程师被困在武汉隔离，创始人 Guillermo Rauch 面临着前所未有的挑战。

然而，危机中往往蕴藏着转机。随着远程办公成为新常态，企业对快速构建高效网站和应用的需求激增。Rauch 敏锐地捕捉到这一趋势，决定将公司重新定位。2020年4月，他宣布将 ZEIT 正式更名为 Vercel——一个融合了"versatile"（多功能）、"accelerate"（加速）和"excel"（卓越）的新名字。

这次转型并非简单的更名。Vercel 的核心产品 Next.js 框架早已在开发者社区中建立了坚实基础。作为 React 的早期贡献者，Rauch 在 2015 年创建了 Next.js，旨在简化前端开发流程。Vercel 平台则为 Next.js 提供了完美的部署环境，支持静态网站和无服务器函数，完美契合了新兴的 Jamstack 架构。

更名后不久，Vercel 宣布获得了 2100 万美元的 A 轮融资，投资方包括 Accel 和 GitHub CEO Nat Friedman。尽管融资在疫情前已完成，但疫情反而验证了 Vercel 的价值主张——帮助企业快速构建面向客户的前端体验。

"我们看到了流量的巨大增长，" Rauch 告诉 Business Insider，"今天的机会是，世界上每家公司都在寻求重塑他们的前端体验，因为他们希望与客户更紧密地联系。"

如今，Vercel 已成为全球顶尖公司的首选平台，客户包括 Airbnb、Uber、GitHub、Nike 和 Ticketmaster。2023 年，公司推出了基于自然语言生成 Web 应用的 AI 工具 v0，并在 2024 年完成了 2.5 亿美元的融资，估值达到 32.5 亿美元。

> "每个公司都在寻求重塑他们的前端体验，因为他们希望与客户更紧密地联系。" —— Guillermo Rauch, Vercel CEO
