# Docker 的逆袭：一个失败PaaS公司的容器革命

2013年，所罗门·海克斯（Solomon Hykes）陷入了困境。他创立的 dotCloud 是一家提供 PaaS（平台即服务）的公司，业务艰难，前景黯淡。更糟的是，他们刚刚从 Y Combinator 毕业，却依然看不到盈利的希望。硅谷的竞争太残酷了——Heroku、Google App Engine、Microsoft Azure 都在瓜分这个市场。

转折发生在一次内部技术分享会上。海克斯决定向团队展示他们为解决自身问题而开发的内部工具——一个可以将应用打包进标准化"容器"的系统。最初这只是为了让 dotCloud 的基础设施更高效，没想到演示结束后，台下有人问："这东西能开源吗？"这个问题像闪电一样击中了海克斯。

几天后，消息泄露到了 Hacker News。Docker 项目一夜之间爆红。开发者们蜂拥而至， downloads 数字飙升——**短短5个月，下载量突破6万次**，每月有8万人访问项目网站。eBay 开始用它来测试新软件，创业公司 MemSQL 用它部署数据库，甚至连 Red Hat 都主动联系寻求合作。

海克斯做出了一个大胆的决定：放弃整个 PaaS 业务，All-in Docker。2013年10月，dotCloud 正式更名为 Docker, Inc.。这是一个赌博——公司账上的钱只够支撑几个月。但海克斯坚信："**每个 Docker 容器都是互联网这个星球级有机体中的一个'细胞'。**"

赌注押对了。Docker 迅速成为云计算领域最具影响力的开源项目之一，彻底改变了软件部署的方式。那个曾经濒临破产的18人小团队，最终催生了一个价值数十亿美元的生态系统。

> "容器只是一个盒子，看似简单。但有了它，你可以打包任何软件产品、平台和系统，最终这些容器无处不在，你可以把它们移动到任何地方。" —— Solomon Hykes
