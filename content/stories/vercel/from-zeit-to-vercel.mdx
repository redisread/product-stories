# Vercel 的华丽转身：从通用云平台到前端部署王者

2019年，Guillermo Rauch 站在十字路口。他的公司 Zeit 虽然技术出色，但在 AWS、Google Cloud 等巨头的夹击下举步维艰。

转折点出现在一次内部讨论中。团队意识到，他们最受欢迎的产品不是通用云服务，而是基于 Next.js 的前端部署解决方案。开发者们疯狂地爱上了这种"git push 即部署"的体验。Rauch 做出了一个大胆决定：放弃通用云平台定位，全力聚焦前端开发者。

接下来的几个月里，团队进行了彻底的重构。他们将产品重新命名为 Vercel（意为"垂直"，象征速度和方向），并围绕 Next.js 构建了完整的生态系统。新平台不仅支持静态站点，还引入了 Serverless Functions 和 Edge Functions，让前端开发者无需后端知识就能构建全功能应用。2020年初，Vercel 正式发布，立即获得了 React 和 Next.js 社区的热烈响应。

短短一年内，Vercel 的用户增长了十倍，包括 The New York Times、Netflix、Uber 等知名企业都成为了客户。更重要的是，Vercel 成功定义了现代前端开发的新范式——以框架为中心的部署体验。

> "我们不是在与 AWS 竞争，我们是在重新定义开发者如何思考部署。" —— Guillermo Rauch
