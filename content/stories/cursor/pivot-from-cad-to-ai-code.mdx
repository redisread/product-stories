# Cursor 的惊天逆转：从 CAD 失败到 AI 编程革命

2022年6月，四个刚从 MIT 毕业的年轻人满怀信心地开始了他们的创业之旅。Michael Truell 和 Aman Sanger 从高中就是好友，他们坚信**AI 将彻底改变机械设计软件**——那个让无数工程师头疼的 CAD 世界。

**转折点发生在六个月后。**

12月的一个深夜，作为 OpenAI Converge 项目的一部分，他们获得了 GPT-4 的早期测试权限。当 Aman 把一段代码粘贴进 GPT-4 的测试界面时，屏幕上的结果让他震惊：**HumanEval 测试得分 85%**，而当时最好的开源模型只有 30%，GitHub Copilot 底层模型也不过 47%。

"我们试了一个月让 CAD 模型学会画一个立方体，" Michael 回忆道，"而 GPT-4 直接理解了整段代码的意图。那一刻我们知道，世界要变了。"

三人立刻停止了 CAD 项目。但他们没有立刻投入编程工具——当时市面上已经充斥着 VS Code 的 AI 插件。他们的洞察更深刻：如果只做一个插件，你永远受制于平台。GitHub 为了让 Copilot 实现多行代码补全，不得不专门请求 VS Code 团队开放 API。

"如果我们想实现真正的 AI 原生编程体验，必须拥有整个 IDE，" Aman 说。这是一个大胆的决定：基于 VS Code 开源版本创建一个全新的编辑器。

2023年1月，Cursor 正式发布。它不只是「带 AI 的编辑器」——**聊天窗口与代码深度融合，你可以用 @ 引用整个代码库，AI 不只是补全代码，而是理解你的整个项目架构**。投资者和用户都被惊艳了：这才是 AI 时代编程该有的样子。

如今，Cursor 已成为全球超过 3 万名开发者的首选工具，NVIDIA、Stripe、OpenAI 等顶级公司都在内部推广。那个曾经想改变 CAD 的四人团队，最终改变了程序员写代码的方式。

> "当你看到技术的临界点，犹豫就是最大的成本。我们在 GPT-4 上看到的不是更好的自动补全，而是整个编程范式的转移。" —— Aman Sanger, Cursor 联合创始人
