# Vercel 的开源豪赌：一个框架如何重塑前端云

【开头】2016年，初创公司 Zeit 面临生死抉择。他们的专有部署平台用户增长停滞，而竞争对手如雨后春笋般涌现。

【转折】创始人 Guillermo Rauch 做出惊人决定：将他们最核心的技术——Next.js 框架完全开源。团队成员激烈反对："这等于把我们的护城河送给竞争对手！"但 Guillermo 坚信："真正的护城河不是代码，而是社区和体验。"

【发展】开源发布当天，GitHub 星标数突破 **1000**。三个月内，Next.js 被 **Netflix、Hulu、Uber** 等巨头采用。开发者们不仅使用框架，还主动贡献代码、修复 bug、编写文档。Zeit 团队发现，开源带来的社区反馈让产品迭代速度提升了 **300%**。2019年，公司正式更名为 Vercel，将品牌与 Next.js 深度绑定。投资者起初质疑这个"免费送核心技术"的策略，但当看到月活跃开发者从 **5万** 暴涨到 **50万** 时，态度彻底转变。

【高潮】2021年，Vercel 完成 **1.5亿美元** D轮融资，估值突破 **25亿美元**。讽刺的是，那些曾经担心开源会毁掉业务的投资人，现在将其视为最明智的战略决策。Next.js 不仅没有削弱 Vercel，反而成为其最强的增长引擎——**90%** 的 Next.js 用户最终都选择了 Vercel 的托管服务。

> "开源不是放弃控制权，而是邀请全世界帮你建造更好的产品。真正的价值不在于你拥有什么，而在于你能为他人创造什么。" —— Guillermo Rauch, Vercel CEO
