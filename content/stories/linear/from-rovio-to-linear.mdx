# Linear 的诞生：从愤怒的小鸟到开发者最爱的工具

【开头】2019年，三位前 Rovio 工程师围坐在赫尔辛基的一家咖啡馆里，对市面上的项目管理工具感到深深的失望。

【转折】Jori Lallo、Ville Vänni 和 Karri Saarinen 在开发《愤怒的小鸟》时，经历了传统工具带来的协作噩梦。他们意识到，现代软件团队需要一个更快、更直观、更专注的工具来跟踪工作。于是，他们决定自己动手创造这个工具。

【发展】团队最初只有三人，但他们有着清晰的愿景：打造一个速度极快、界面简洁、体验流畅的 issue tracking 工具。他们拒绝了复杂的配置和臃肿的功能，专注于核心工作流。在开发过程中，他们坚持每天使用自己的产品，确保每一个细节都符合开发者的真实需求。2020年初，Linear 正式发布，迅速在硅谷科技圈引起轰动。不到一年时间，GitHub、Figma、Notion 等顶级科技公司都成为了他们的用户。到2022年，Linear 已经获得了超过5000万美元的风险投资，估值超过10亿美元。

【高潮】Linear 的成功不仅在于技术实现，更在于它重新定义了开发者的工作方式。它将 Slack 的即时通讯体验、Figma 的实时协作和 Apple 的设计哲学融为一体，创造了一个让开发者真正爱用的工具。今天，全球数千家科技公司依赖 Linear 来管理他们的产品开发流程。

> "我们不是在构建另一个 Jira。我们是在重新思考软件团队应该如何工作。" — Jori Lallo, Linear 联合创始人
