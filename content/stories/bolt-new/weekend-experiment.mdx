# Bolt.new 的意外诞生：一个周末的疯狂实验

2024年3月的一个周五下午，StackBlitz 创始人 Eric Simons 做了个梦。

> "我梦见一个界面，你只要说一句话，整个应用就出来了。不是生成代码片段，是完整的、可运行的、可以直接部署的应用。"

他把这个梦告诉团队。有人说这太疯狂了。

## 48小时的疯狂

那个周末，团队没回家。他们用 WebContainer API——StackBlitz 花了三年做的浏览器里运行 Node.js 的技术——加上大模型 API，做了个粗糙的原型。

周一早上，他们给投资人展示了演示。一个全栈应用，从需求到部署，不到10分钟。

投资人的反应是：「这不可能。」

## 真正的转折点

但真正改变一切的，不是投资人的钱，而是一个用户的推文。

2024年5月，Bolt.new 刚开始小范围测试。一位独立开发者发推：「我用 Bolt.new 做了我老婆的婚纱电商店铺。我不会写代码。我用了不到两小时。」

这条推文被转了3000多次。Eric 意识到：**他们不是在做一个工具，是在消除编程的门槛。**

## 从玩具到生产力

团队开始重新思考产品定位。原本想做「AI 编程辅助」，后来改成「AI 全栈开发」。区别在于：不是帮程序员写代码更快，而是让不会编程的人也能做应用。

> "我们不是在和 VS Code 竞争。我们是在和「不会编程」这个事实竞争。"

2024年9月，Bolt.new 正式发布。到了12月，月活用户突破100万。
