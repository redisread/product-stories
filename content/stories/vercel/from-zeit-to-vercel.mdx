# Vercel 的重生：从 ZEIT 到前端革命

【开头】2020年初，29岁的吉列尔莫·劳赫陷入困境。他的工程师被困在武汉，全球疫情爆发，科技投资急剧放缓。

【转折】然而，就在这个看似绝望的时刻，劳赫做出了一个大胆的决定：将他的公司 ZEIT 重新命名为 Vercel，并宣布获得2100万美元的融资。这个时机看似疯狂，却恰恰抓住了历史机遇。

【发展】劳赫早在2015年就创立了 ZEIT，专注于为开发者提供构建更好用户界面的工具。作为 React 框架的早期贡献者，他开发了 Next.js——一个基于 React 的开源框架，后来成为 Vercel 平台的核心。当疫情迫使全球转向远程工作时，企业急需快速构建和部署网站的能力。Vercel 的流量激增，Airbnb、Uber、GitHub、Nike 等大客户纷纷采用其服务。"每家公司都在寻求重塑他们的前端体验，因为他们想要更接近客户，"劳赫告诉 Business Insider。

【高潮】Vercel 的成功不仅在于技术，更在于时机的把握。当其他初创公司裁员收缩时，Vercel 却在扩张。他们举办的虚拟技术会议获得了广泛好评，展示了远程协作的可能性。从 ZEIT 到 Vercel 的转变，标志着从前端工具提供商到完整开发平台的跃迁，彻底改变了现代 Web 开发的工作流程。

> "我们今天的机会是，世界上每家公司都在寻求重塑他们的前端体验，因为他们想要更接近客户。"
