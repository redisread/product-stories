# Linear 的诞生：Airbnb 工程师逃离 Jira 的自救之旅

2018 年，Airbnb 的设计系统负责人 Karri Saarinen 坐在办公桌前，盯着加载中的 Jira 界面，感到一阵绝望。

每一次点击都要等待数秒，每一个操作都像在泥潭中跋涉。作为 Airbnb 设计系统的负责人，他需要与数十名工程师协作，但工具本身成了最大的阻力。

## 一个大胆的实验

一天，Karri 找到工程师 Jori Lallo，提议了一个疯狂的想法：**为什么不自己做一个工具？**

两人利用业余时间，开始构建一个内部原型。他们的目标很简单：**快得像闪电，美得像艺术品**。没有臃肿的功能，没有缓慢的加载，只有纯粹的效率。

三个月后，这个内部工具在 Airbnb 的小团队中传开了。"这太快了！"同事们惊叹。但 Karri 和 Jori 意识到，如果仅仅停留在内部，这个工具永远无法帮助更多受困于 Jira 的开发者。

## 关键抉择

2019 年初，两人面临人生中最艰难的决策：留在 Airbnb 拿着丰厚的薪水，还是冒险全职创业？

Karri 回忆说："我们知道市面上有数百万开发者每天在忍受糟糕的工具。如果我们不做，谁会做？"

**2019 年 4 月，他们正式离开 Airbnb**，成立了 Linear。同月，他们从红杉资本获得了 **400 万美元**的种子轮融资。

## 意外走红

Linear 的测试版发布后，反响远超预期。开发者们蜂拥而至，称赞它"重新定义了问题追踪"。

没有销售团队，没有营销活动，仅靠口碑传播，Linear 在发布一年内就吸引了 **Segment、Vercel、Mercedes-Benz** 等顶级公司成为客户。

如今的 Linear 已估值数十亿美元，但 Karri 和 Jori 依然保持着最初的信念：工具应该是优雅的，开发者的每一天都值得更好的体验。

> "我们不是为了颠覆而创业，我们只是受不了每天被糟糕的工具折磨。如果你也对现状不满，那可能是世界在等你做出改变。"
> 
> —— Karri Saarinen, Linear CEO
