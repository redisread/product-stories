# Supabase 的诞生：开源如何挑战科技巨头

【开头】2020年，Paul Copplestone 和 Ant Wilson 在 Y Combinator 的办公室里，面对一个看似不可能的挑战：打造一个能与 Google Firebase 竞争的开源替代品。

【转折】两人都是经验丰富的开发者，深知 Firebase 的便利性，但也清楚其闭源架构带来的限制。他们相信，现代应用开发需要一个真正开放、可扩展且基于成熟技术栈的解决方案。于是，他们决定以 PostgreSQL 为核心，构建一个开源的实时数据库平台。

【发展】初期资金只有 Y Combinator 提供的 12.5 万美元，团队只有两人。他们选择了完全透明的开发模式，在 GitHub 上公开所有代码和路线图。这种策略意外地吸引了大量开发者的关注和贡献。2020年9月，Supabase 正式发布 Beta 版本，立即在 Hacker News 上引发热议。到2021年底，GitHub 星标数突破 2 万，社区贡献者超过 300 人。2022年，他们获得了 3000 万美元的 A 轮融资，估值达到 1 亿美元。关键转折点发生在 2023年，当一家 Fortune 500 公司选择 Supabase 而非 Firebase 作为其核心基础设施时，这证明了开源方案在企业级应用中的可行性。

【高潮】今天，Supabase 已经成为全球最受欢迎的开源 BaaS（后端即服务）平台，拥有超过 10 万活跃开发者和数千家企业客户。它不仅提供了 Firebase 的所有核心功能，还通过 PostgreSQL 的强大能力实现了更复杂的查询和数据操作。更重要的是，它证明了开源项目可以在不牺牲商业成功的情况下，为开发者提供真正的选择权和控制权。

> "我们不是要取代 Firebase，我们要证明开源可以做得更好。" — Paul Copplestone, Supabase 联合创始人
