# Linear 的诞生：当设计师对糟糕的工具说不

## 【开头 - 50字】
2019年，三位来自《愤怒的小鸟》开发商 Rovio 的设计师围坐在赫尔辛基的一家咖啡馆里，讨论着一个共同的痛点。

## 【转折 - 100字】
他们厌倦了 Jira、Asana 和 Trello 等工具的复杂性和低效性。这些工具要么过于笨重，要么缺乏必要的功能，让团队协作变得痛苦而非愉悦。Karri Saarinen、Jori Lallo 和 Tuomas Artman 决定不再忍受，而是自己创造解决方案。

## 【发展 - 200字】
三人利用在 Rovio 积累的设计经验，开始构建一个全新的项目管理工具。他们坚持"速度即特性"的理念，认为优秀的工具应该让团队快速完成工作，而不是陷入繁琐的流程中。Linear 的名字本身就体现了这一理念——线性、直接、高效。

他们从零开始，专注于打造流畅的用户体验。每个交互细节都经过精心打磨，从键盘快捷键到实时协作，从简洁的界面到强大的 API 集成。作为完全远程的团队，他们深知分布式协作的挑战，因此将异步沟通和透明度作为核心设计原则。

早期用户主要是其他设计和技术团队，他们立即感受到了 Linear 带来的效率提升。与传统工具需要数小时配置不同，Linear 开箱即用，让团队能在几分钟内开始高效协作。

## 【高潮 - 100字】
Linear 迅速在硅谷科技圈走红，吸引了包括 Figma、Stripe 和 Airbnb 在内的顶级公司采用。2021年，他们获得了由 Sequoia 领投的4400万美元B轮融资。到2023年，Linear 已成为高增长科技团队的首选项目管理工具，证明了"设计驱动"的产品哲学在企业软件领域的巨大潜力。

## 【金句结尾 - 50字】
> "我们不是在构建另一个工具，而是在重新定义团队如何一起工作。" — Karri Saarinen, Linear 联合创始人兼 CEO
