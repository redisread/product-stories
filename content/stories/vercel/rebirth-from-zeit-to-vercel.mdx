# Vercel 的绝境重生：从 ZEIT 到全球开发平台

2020年初，29岁的吉列尔莫·劳赫陷入困境。他的初创公司 ZEIT 最优秀的工程师被困在武汉，全球疫情爆发导致科技投资急剧放缓。

## 绝境中的决定

就在所有人都在削减开支时，劳赫做出了一个大胆的决定：不仅不裁员，反而要彻底重塑公司。他将 ZEIT 更名为 Vercel，并宣布获得 Accel 和 GitHub CEO 纳特·弗里德曼领投的 2100 万美元融资。这个决定看似疯狂——在全球经济衰退的阴影下进行品牌重塑和扩张。

## 前端革命的幕后

劳赫并非无名之辈。作为 React 框架的早期贡献者，他早在 2015 年就创建了 ZEIT 来解决前端开发的痛点。他开发的 Next.js 框架已经成为现代 Web 开发的基石。但 ZEIT 这个名字始终未能完全传达公司的使命。

"每家公司都在寻求重塑他们的前端体验，因为他们想要更接近客户，"劳赫在接受采访时说。疫情期间，企业急需快速构建新的网站和应用来应对危机，Vercel 的平台正好满足了这一需求。Airbnb、Uber、GitHub、Nike 等巨头都成为了他们的客户。

## 转型的成功

更名后的 Vercel 流量激增。远程工作的兴起让开发者们更加依赖高效的云端开发工具。Vercel 不仅提供了部署解决方案，还通过 Git 集成实现了无缝的开发体验。到 2021 年，他们又筹集了 1.02 亿美元的 C 轮融资，估值飙升。

## 黄金时刻

> "危机不是障碍，而是加速器。当世界被迫数字化时，我们已经准备好了。" — 吉列尔莫·劳赫，Vercel CEO
