# Linear 的零缺陷执念：一个软件团队的质量革命

2019年，Karri Saarinen、Jori Lallo 和 Tuomas Artman 从 Uber 和 Pinterest 离职，决心打造一款真正优秀的软件开发工具。他们厌倦了行业内的妥协文化——"快速行动，打破常规"、"先发布再修复"。Linear 从诞生之初就选择了不同的道路。

转折点出现在2023年。团队发现用户报告的某个缺陷竟然在其他应用中存在了整整五年才被修复。Tuomas Artman 回忆道："数百万用户白白忍受了五年的痛苦，这完全不可接受。" 这一发现促使 Linear 正式确立了"零缺陷"政策：所有缺陷必须立即修复，高优先级缺陷48小时内解决，其他缺陷7天内处理。

Linear 的零缺陷政策不仅仅是技术决策，更是价值观宣言。团队暂停了所有新功能开发，用三周时间清空了175个积压的缺陷。此后，他们建立了严格的流程：每个工程师每天早上第一件事就是处理分配给自己的缺陷；每周审查缺陷仪表板，确保负载均衡；任何新功能都必须通过"零缺陷"标准才能发布。这种做法彻底改变了团队与用户的关系——用户报告缺陷后常常在当天就收到修复，将负面体验转化为对产品的信任。

结果令人震惊：Linear 在两年内修复了超过2000个缺陷，同时保持了高速的产品迭代。更重要的是，这种质量文化吸引了志同道合的顶尖工程师和客户。包括 OpenAI、CashApp、Ramp 在内的15,000多家公司选择 Linear，不是因为它的功能最多，而是因为它提供了最可靠的体验。正如 Karri Saarinen 所说："质量不是自动产生的，它需要刻意为之。"

> "当我们讨论是否要放弃零缺陷政策时，答案是一致的：没有人能想象回到低质量产品的状态。对我们来说，这不是一个选项。" —— Tuomas Artman, Linear 联合创始人兼CTO
