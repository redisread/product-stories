# Vercel 的绝境重生：从 ZEIT 到前端开发革命

## 开头

2015年，Guillermo Rauch 站在人生的十字路口。这位曾创造 Socket.IO 的天才开发者，刚刚经历了一次创业失败。

## 转折

Rauch 没有放弃，而是将目光投向了 React 生态系统中的一个痛点：开发者需要一个更简单的方式来构建和部署 React 应用。他创建了 Next.js——一个基于 React 的服务端渲染框架，并成立了 ZEIT 公司来支持它。

## 发展

ZEIT 最初只是一个小型工具集，但 Next.js 迅速在开发者社区中获得了关注。Rauch 和他的团队发现，他们创造的不仅仅是一个框架，而是一个全新的开发范式。2020年初，当新冠疫情席卷全球时，ZEIT 面临着前所未有的挑战——他们的首席工程师被困在武汉，无法工作。然而，危机也带来了机遇：远程工作需求激增，企业急需快速构建和部署网站的能力。

Rauch 做出了一个大胆的决定：将公司从 ZEIT 重新命名为 Vercel（"vertical" 和 "cell" 的组合），并完全专注于为 Next.js 构建一个无缝的部署平台。这个新平台允许开发者通过 Git 提交代码后自动部署，并为每次提交生成预览 URL，彻底改变了前端开发的工作流程。

## 高潮

重命名后的 Vercel 迅速获得了市场认可。GitHub CEO Nat Friedman、Accel 等顶级投资者纷纷注资。到 2021 年，Vercel 已经拥有包括 Airbnb、Uber、GitHub 在内的重量级客户，并完成了 1.02 亿美元的 C 轮融资，估值达到 11 亿美元。Next.js 也成为全球前 10,000 个网站中增长最快的框架之一。

## 金句结尾

> "我们的目标是赋能前端开发者，让他们能够创造出令人愉悦、沉浸式的网络体验。" —— Guillermo Rauch, Vercel CEO
