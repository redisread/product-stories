# Linear 的反叛：三个前 Airbnb 工程师如何颠覆项目管理

【开头】2019年，Jori Lallo、Ville Vänni 和 Karri Saarinen 坐在旧金山的一家咖啡馆里，愤怒地讨论着 Jira 的糟糕体验。

【转折】这三位前 Airbnb 工程师已经受够了市场上笨重、复杂的项目管理工具。他们意识到，如果连他们这些技术专家都无法高效使用现有工具，那么普通团队更是寸步难行。就在那天，他们决定从零开始，打造一个"开发者真正会喜欢使用"的工具。

【发展】Linear 的创始团队有一个激进的理念：软件应该像 iPhone 一样优雅易用。他们拒绝添加任何可能降低用户体验的功能，即使这意味着短期内功能不如竞争对手丰富。在开发初期，他们甚至拒绝了知名风投的数百万美元投资，只为了保持对产品方向的完全控制。团队坚持每周发布新版本，直接与早期用户对话，快速迭代。到 2020 年底，Linear 已经吸引了包括 Coinbase、Notion 和 Figma 在内的顶级科技公司作为客户，尽管他们几乎没有进行任何市场营销。

【高潮】2021年，Linear 宣布获得 1300 万美元 A 轮融资，估值迅速飙升。更重要的是，他们证明了一个看似不可能的观点：开发者工具也可以拥有消费级产品的用户体验。如今，Linear 已成为硅谷最热门的初创公司之一，彻底改变了人们对项目管理工具的认知。

> "我们不是在构建另一个 Jira。我们在构建开发者每天醒来都期待使用的工具。" — Jori Lallo, Linear 联合创始人
