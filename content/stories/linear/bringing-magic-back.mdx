# Linear 的诞生：三位匠人决定找回软件的魔法

2019 年，Karri Saarinen 陷入了深深的沮丧。作为 Airbnb 和 Coinbase 的前设计负责人，他见证了太多优秀的软件团队被糟糕的工具折磨——Jira 的页面加载需要数秒，创建一个问题要点击十几个按钮，看板视图像是从上世纪穿越而来。

"**计算机曾经是有魔法的**，"Karri 对他的前同事 Jori Lallo 和 Tuomas Artman 说，"但那种魔法已经消失了。"三人坐在各自的远程办公桌前，通过 Zoom 相望——他们都曾在硅谷顶级公司工作，都体验过优秀工具的力量，也都被现状伤透了心。

那个晚上，他们做出了一个大胆的决定：**不为企业做软件，而为工匠做工具**。他们要为那些真正在乎质量的团队，打造一款既快速又优雅的项目管理工具。Linear 的名字由此而来——它代表着一种简洁、直接的进步方式。

真正的挑战在于细节。他们花了 **三个月** 只打磨一个问题创建界面的键盘交互；为了让同步体验达到毫秒级，Tuomas 重写了三次底层架构；Jori 坚持每一个过渡动画都必须有物理质感。投资人质疑他们是否在小题大做，但 Karri 只说了一句："**当你在乎时，就没有细节是小的。**"

2020 年，Linear 悄然发布。没有宏大的发布会，没有媒体报道——但开发者们立刻察觉到了不同。从 Vercel 到 Mercury，从 Stripe 到 Notion，口碑在工程师之间病毒式传播。**上线第一年，就有 50 家顶级初创公司全面迁移到 Linear**。

今天，Linear 已经服务了数千个团队，从两人初创公司到上市科技巨头。但三位创始人依然坚持远程工作，团队保持精悍，每一个像素依然被认真对待。

> "我们不只是在做一个更好的工具，而是在创造一种更好的工作方式。软件 craftsmanship 的魔法，值得被重新找回。"
> —— **Karri Saarinen**, Linear CEO
