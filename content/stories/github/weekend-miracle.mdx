# GitHub 的周末奇迹：三个开发者的协作革命

2008年的一个普通周末，汤姆·普雷斯顿-沃纳、克里斯·万斯特拉斯和PJ·海耶特坐在旧金山的公寓里，对现有的代码托管工具感到沮丧。

## 周末的灵光一闪

他们原本只是想解决自己的问题：Git虽然强大但难用，现有的托管服务缺乏社交功能。三人决定创建一个既能简化Git操作，又能让开发者轻松协作的平台。这个周末项目最初只是为了解决他们自己的痛点。

## 从车库到全球

GitHub的核心创新在于将社交网络的概念引入代码托管。他们实现了"fork"和"pull request"功能，让任何人都能轻松地贡献代码。上线第一天只有几十个用户，但开发者们口口相传，用户数呈指数级增长。到2010年，GitHub已经托管了超过100万个代码仓库，包括Ruby on Rails、jQuery等知名项目。

微软、谷歌、Facebook等科技巨头都开始使用GitHub。平台不仅改变了开源项目的协作方式，也重塑了企业内部的开发流程。2018年，微软以75亿美元收购GitHub，创下了开发者工具领域的收购纪录。

## 开发者的家园

> "我们不是在构建工具，而是在构建社区。代码是社交的。" — 汤姆·普雷斯顿-沃纳，GitHub联合创始人
